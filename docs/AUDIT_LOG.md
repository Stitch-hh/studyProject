# Аудит-лог «играю и придираюсь»

Метод: проход всех состояний прототипа с вопросами «так и должно работать / выглядеть /
быть здесь / сейчас?» + проверка подачи текстов (зацепка vs ТЗ) + цепочки квестов.
Серьёзность: **крит** (ломает игру/ожидание), **баг** (неверно работает/противоречит докам),
**полировка** (стиль/читаемость), **вопрос** (решение за арбитром — не чиним сами).

### Повторный проход (после фиксов)
Сид из ссылки открывает ту самую смену (`?seed=2`: интро «Заступить на смену #2» →
планёрка с «Законной охотой» → вызов 0 эскалирован ⚠ → вызов 1 свидетель 👁 →
экран «Свидетель всё видел» → лицензии в Реестре → утренний отчёт с ответом Тьмы).
Смоук: 1000 сидов планёрки (0 finale, все 49 первичных выпадают), 500 полных смен
с авто-боями — 0 крашей. Новых находок уровня крит/баг — 0.

### Вопросы арбитру (итерация 1)
1. **Связка Силы смены и боя (№9):** как должно быть? Варианты: (а) бой стартует с текущей Силой смены и возвращает остаток; (б) бой — отдельный «оперативный резерв», а Сила смены — «стратегическая» (тогда подписать в UI); (в) как сейчас, но с пояснением.
2. **Эскалация и бои (№10):** усиливать врага в эскалированных боевых инцидентах (+HP/скорость), или баннер эскалации на боевых опциях не показывать?
3. **intake-desk (№11):** оставить как редкий «дневной» вызов с правкой текста, или убрать из пула (механика планёрки уже покрывает)?
