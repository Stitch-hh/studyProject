# Как запускать «Смену» и пробовать играть

Короткая инструкция: что нажимать, чтобы после каждого обновления открыть
прототип у себя и поиграть. Всё — в терминале, копируй команды как есть.

> Это прототип (этап 0 — смена и планёрка, этап 0.5 — бой). Графика минималистичная,
> но все механики уже живые: разбор заявок, баланс, бой с овердрайвом.

---

## 0. Что нужно один раз поставить

**Node.js** версии 20 или новее (в нём уже есть `npm`).

- Скачать: https://nodejs.org — бери кнопку **LTS**.
- Проверить, что встал, — в терминале:
  ```bash
  node --version   # должно показать v20… или новее
  npm --version
  ```

Если `node` не находится — перезапусти терминал после установки.

---

## 1. Первый раз: скачать проект

Выбери папку, куда положить игру, и в терминале:

```bash
git clone https://github.com/Stitch-hh/studyProject.git
cd studyProject
git checkout claude/dozory-game-concept-beas9s
npm install
```

`npm install` скачает зависимости — это нужно один раз (и потом ещё раз только
если менялись библиотеки; см. ниже).

---

## 2. Каждый раз, когда я обновил игру

Ты уже внутри папки `studyProject`. Забрать свежую версию и запустить:

```bash
git pull origin claude/dozory-game-concept-beas9s
npm install        # быстро, если ничего в зависимостях не поменялось
npm run dev
```

В терминале появится строчка вида:

```
  ➜  Local:   http://localhost:5173/
```

Открой этот адрес (`http://localhost:5173`) в браузере — игра запущена.

Чтобы **остановить** сервер — вернись в терминал и нажми `Ctrl + C`.

> Терминал во время игры не закрывай: пока `npm run dev` работает, страница живая
> и сама подхватывает изменения.

---

## 3. Как играть (что происходит на экране)

1. **«Заступить на смену».** Стартовый экран.
2. **Разбор заявок (планёрка).** Приходит 8 сводок: часть — реальные угрозы,
   часть — жёлтая пресса (утки). У тебя всего **3 часа аналитика** — можно
   разметить только 3 заявки. Смотри на курсив под каждой заявкой (сигнал
   достоверности) и решай, кого брать в приоритет.
   - Размеченное реальное дело ночью пойдёт **с меньшим риском** (подвох известен).
   - Разметишь утку — потратишь час впустую.
   - Реальную угрозу, которую не разметил, к утру **раздует** — риск вырастет.
3. **Смена (20:00 → 08:00).** Идёшь по вызовам. У каждого — варианты:
   **БУМАГА / СЛОВО / СИЛА / МИМО / ЛИЧНО**. Под вариантом написана цена:
   минуты, Сила, деньги, кому уходит лицензия/компенсация, риск (`↓` — снижен
   разметкой, `↑` — раздут).
   - **Баланс** вверху: любое силовое вмешательство Света даёт Тьме право на
     ответ. Цель — не бить сильнее всех, а платить меньше.
4. **Бой** (некоторые дела). Пример — «Законная охота» (вампирша) и «Соляной
   круг» (ведьма). В бою:
   - Выбираешь заклинание и **сколько Силы влить**. Хочешь большие числа —
     впитай амулет (кнопка ⚡) и вливай сотни Силы в один удар: это **овердрайв**.
   - «Рефлекс» — заготовленные мгновенные заклинания.
   - «Черпать Силу» — восстановить резерв (но ты открыт).
5. **Утренний отчёт.** Ответ Тьмы по Реестру, оценка смены (S…F), спасённые,
   жертвы, огласка, баланс, деньги, репутация.

**Попробовать только бой:** на стартовом экране есть кнопка
**«⚔ Испытать бой (этап 0.5)»** — сразу боевая сцена, без смены.

**Переиграть ту же смену:** в адресе есть `?seed=…`. Один и тот же seed = одна
и та же расстановка заявок и вызовов (удобно сравнивать решения). Кнопки
«Переиграть смену #…» делают то же самое.

## 4. Если что-то не так

- **`http://localhost:5173` не открывается** — посмотри в терминал: возможно,
  Vite занял другой порт (`Local: http://localhost:5174/`). Открой тот адрес.
- **Порт занят / висит старый сервер** — нажми `Ctrl + C` в терминале и снова
  `npm run dev`.
- **Пустая страница** — обнови вкладку жёстко: `Ctrl + Shift + R`
  (на Mac — `Cmd + Shift + R`).
- **`npm run dev` ругается на версию** — проверь `node --version`, нужно 20+.
- **`git pull` ругается на локальные изменения** — если ты ничего не правил
  специально, можно откатить к моей версии:
  ```bash
  git reset --hard origin/claude/dozory-game-concept-beas9s
  ```
  (осторожно: это сотрёт твои несохранённые правки в файлах игры).
