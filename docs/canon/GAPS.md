## 4. Зоны свободного дизайна по приоритету для игры

### 🔥 Ядро прототипа (этапы 0–1): Реестр, инциденты, доска

Канон молчит — наши правила законны, оформлять 🛠:

- Полная таблица семи степеней вмешательства; формула расчёта степени
  (4-treaty §4.34.1–2).
- Точный механизм возникновения встречного права; автоматический Реестр,
  фиксирующий каждое заклинание; численное равенство компенсаций
  (§4.34.3–5) — ядро нашей шкалы Баланса.
- Срок действия и территория права; дробление и объединение прав; рынок
  лицензий; **оформление задним числом** (наша опция «БУМАГА»)
  (§4.34.6–11).
- Процедура вампирской лотереи целиком: розыгрыш, уведомление, выкуп,
  замена, добровольцы (§4.34.12–14) — готовый простор для инцидентов.
- Категории человеческого допуска к Тайне; работа с облачными записями;
  осведомлённость спецслужб (7-society §7.19.17–19) — правила нашей
  «огласки».
- Стандарт доказывания, апелляции, защита в Трибунале (§4.34.18–20).
- Юридическая степень каждого конкретного заклинания (6-magic §6.55.40) —
  наша таблица «заклинание → степень» будет целиком 🛠.

### ⏳ Бой, классы, крафт (этапы 0.5–2)

- Все числовые параметры заклинаний: стоимость, радиусы, длительности,
  время каста, промах, сопротивление, взаимодействие щитов (6-magic
  §6.55.1–14) — заполняется балансом, маркировать D/🛠.
- Число слотов заготовок и срок их хранения (§6.55.8–9) — наши «2–5
  слотов» легальны.
- Частота кормления вампира; полный ритуал обращения; ранги иерархии
  (5-creatures §5.14.1–6).
- Механика оборотнического укуса и первой трансформации; расход Силы
  перевёртыша (§5.14.8–13).
- Полная механика проклятий; рецептура и сроки зелий; стандарты зарядки
  накопителей; износ артефактов (6-magic §6.55.27–34).
- Структура Конклава ведьм; шабаши; светлые аналоги ведьм (§5.14.16–18).
- Табельное снабжение, стандартная опергруппа, аттестация новичка,
  система званий (8-watches §8.17.19–24) — свобода для нашего штаба.
- Цена перехода и пребывания по слоям; минимальные уровни; проводники и
  пассажиры (2-twilight §2.28.9–14).

### 🌙 Поздняя игра и фон

- Природа Сумрака, механизм его жизни, происхождение слоёв, «что вне
  кольца» (2-twilight §2.28.1–5, 35).
- Посмертие: чем питаются умершие, вывод через 7-й слой, кто кроме Нади
  замыкает кольцо (§2.28.29–32).
- Полный дуэльный кодекс; международная экстрадиция; признание иностранных
  лицензий (4-treaty §4.34.23–25).
- Экономика общества: зарплаты, бюджеты, налоги, магические банки,
  наследование бессмертных, документы нестареющих (7-society §7.19.1–8).
- Семейное право Иных, регистрация детей, школы (§7.19.12–16).
- Генетика потенциала, демография, продолжительность жизни по категориям
  (3-others §3.19.1–3, 13, 18–19).
- Национальная и мировая вертикали Дозоров; пенсия; резервисты; сеть
  нейтральных территорий (8-watches §8.17.7–9, 27–29).
- Хронология влияния Иных на историю; доктрины сторон по эпохам
  (7-society §7.19.21–22).

## 5. Приоритетные углубления (план следующей итерации)

По решению автора, следующие итерации — не новые разделы, а углубления:

1. **Точная таблица заклинаний** — свести каталог 6-magic §6.5–6.35 в
   игровую библиотеку: имя (потом переименование по легальному словарю) →
   канонный эффект → наши числа (🛠) → юридическая степень (🛠).
2. **Классы вмешательств** — превратить подтверждённые точки шкалы
   (4-treaty §4.10) в полный игровой тарифник VII–I с примерами для
   генератора инцидентов.
3. **Послойные свойства Сумрака** — карточки слоёв (2-twilight §2.10–2.16)
   → игровые параметры: цена входа/тика, что видно, что хранится, что
   работает (после решения расхождений 1–3).
