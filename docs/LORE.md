# Канон-справочник

Источник истины по лору для всех игровых решений. Правило: **механика не может
противоречить фактам из этого документа**. При конфликте канон побеждает дизайн.

Маркировка каждого факта:

- 📖 — канон книг
- 🎮 — канон онлайн-игры «Дозоры» (dozory.ru)
- 🛠 — наш дизайн: допущение, не противоречащее канону
- 🔮 — предварительный канон: опубликованные фрагменты «Вечного Дозора»;
  не использовать как единственное основание игровой механики
- ❓ — требует проверки по книгам (см. последний раздел)

Градация надёжности книжного факта (уточнение к 📖, ставится при
необходимости): **A** — прямой поздний канон («Новый»/«Шестой Дозор»);
**B** — прямой основной канон (любой из шести романов, не опровергнут);
**C** — повторяющийся вывод из нескольких эпизодов; **D** — расширенный
канон (рассказы, межавторские книги, dozory.ru); **E** — зона свободного
дизайна (в источниках ответа нет).

Документ пополняется по мере работы. Верховный арбитр канона — автор проекта;
AI обязан сверять каждый новый контент с этим файлом и не добавлять сюда
факты без пометки источника. Развёрнутые канон-исследования по разделам
опросника [CANON_QUESTIONS.md](CANON_QUESTIONS.md) лежат в `docs/canon/` —
этот файл хранит выжимку.

## Рамка канона

Полное исследование: [canon/0-framework.md](canon/0-framework.md).
Операционные правила:

- **Жёсткий канон — шесть романов основного цикла**: «Ночной Дозор»,
  «Дневной Дозор» (Лукьяненко и Васильев — тоже жёсткий канон: Зеркало,
  Алиса Донникова, Виталий Рогоза, трибунал), «Сумеречный Дозор»,
  «Последний Дозор», «Новый Дозор», «Шестой Дозор».
- **Приоритет при конфликте** (по убыванию): Шестой → Новый → Последний →
  Сумеречный → Дневной → Ночной → рассказы Лукьяненко → межавторские
  романы → онлайн-игра. Поздняя основная книга сильнее ранней и сильнее
  любого более нового межавторского произведения.
- **Раннее противоречие** трактуется как неполное знание POV-персонажа
  (Антона), а не альтернативная физика мира. Старую версию сохраняем в
  карточке правила рядом с поздней.
- **«Вечный Дозор»** (не завершён) — 🔮 предварительный канон: авторская
  гипотеза, гексалогию не переписывает.
- **Рассказы** Лукьяненко — канон, если не противоречат романам и не
  являются юмористической/рекламной стилизацией; вес ниже романов.
- **Онлайн-игра** — источник классов; девонов НЕ используем; её числа,
  школы и умения не равны книжному канону автоматически.
- **Фильмы 2004–2005 — НЕ источник канона** (самостоятельная адаптационная
  непрерывность); ничего из них без отдельной книжной проверки.

## Словарь проекта (легальная терминология)

Пока нет прав на франшизу, в игровых текстах используется своя терминология
(см. GD, раздел 3). Все замены — 🛠 наш дизайн; в документах лора и GD для
ясности пользуемся канонными словами.

| Канон (книги) | В игре | Комментарий |
|---|---|---|
| Иные | **Пробуждённые** | Пробуждены к Изнанке |
| Люди (не-Иные) | **люди** | Обычное слово — замена не нужна, используется как есть |
| Ночной/Дневной Дозор | **Ночная/Дневная стража** | |
| Сумрак | **Изнанка** | |
| Договор | **Реестр** | Также место записи лицензий |
| Инквизиция | **Арбитры** (ед. ч. — арбитр, «судьи») | |

Правило: новый охраняемый термин канона не попадает в игровые тексты без
строки в этой таблице.

## Иные

- 📖 Иные — люди с врождённой способностью входить в Сумрак и оперировать
  Силой. Способность обнаруживается; требуется инициация.
- 📖 Иные не производят Силу сами — черпают её от людей и их эмоций.
- 📖 Уровни силы — обратная шкала: с седьмого (слабейший, минимальный
  устойчиво распознаваемый) по первый; выше — Высшие, «вне категорий» и
  нулевой/Абсолютный как предельное значение (Надя). Относится ко ВСЕМУ:
  уровням Иных, заклинаний, воздействий, лицензий.
  🛠 Правило для кода и UI: в данных храним канонический уровень (7…1);
  для арифметики (баланс, счёт) используем «весомость» = 8 − уровень.
  ⚠️ Анти-ошибка: инвертированная шкала «чем больше номер, тем сильнее»
  успела попасть в прототип и была вычищена — не повторять.
- 📖B Уровень — врождённый потенциал, линейной тренировкой не растёт.
  Тренировка растит мастерство: контроль, скорость, репертуар, экономию
  Силы, скрытие ауры — опытный слабый может победить сильного новичка.
  Качественный рост уровня — только раскрытие потенциала или
  исключительное событие (путь Антона, «Фуаран», функция Зеркала).
  Подробно: [canon/1-power.md](canon/1-power.md) §1.9.
- 📖B «Фуаран» — превращает человека в Иного и повышает уровень
  существующего Иного («Сумеречный Дозор», Костя Савушкин → Высший
  вампир). Уникально и катастрофически редко: нужен текст/структура
  заклинания и материал многих Иных разных уровней; массовое применение
  разрушает миропорядок. §1.10.
- 📖B Различать пять разных вещей: реальный уровень / официально
  зарегистрированную категорию / оценку наблюдателя / текущий запас /
  временное усиление. §1.12.
- 📖A «Вне категорий» — не «большой запас», а выход за применимость шкалы:
  качественно иные техники (Завулон в «Шестом Дозоре» прячется МЕЖДУ
  слоями Сумрака). Ограничения остаются: не бессмертие, не всезнание, не
  право игнорировать Договор. §1.13.
- 📖A Надя — «нулевая»/Абсолютная волшебница: ноль — верх обратной шкалы,
  предельный потенциал. НЕ означает постоянную боеготовность: нуждается в
  обучении, физически уязвима, под тройным контролем (оба Дозора +
  Инквизиция). §1.14.
- 📖B Аура есть у людей, Иных, вампиров, оборотней, предметов, пищи, мест,
  заклинаний, артефактов («Шестой Дозор»: аура кастрюли хранит историю
  вещи). По ауре — в зависимости от силы, опыта и специализации
  наблюдателя — видно: человек/Иной/потенциал, инициированность, сторона,
  примерный уровень, природа, внушения, следы магии. ⚠️ Аура — НЕ
  интерфейс с карточкой «вампир, ур. 4, запас 73%». Потенциального Иного
  можно пропустить (слабый потенциал, толпа, маскировка). §1.15–1.18.
- 📖B Сторона потенциального Иного до инициации не обязательно закреплена
  окончательно (уточнение к правилу «сторона фиксируется при инициации»).
  §1.18.
- 📖A Маскировка ауры возможна: приглушить, исказить, подделать уровень,
  закрыть артефактом. Работает тем надёжнее, чем слабее наблюдатель.
  Выдаёт: слишком чистая аура, несоответствие мощности заявленному уровню,
  почерк, след самой маскировки. Подделка стороны — сложна и ненадёжна,
  простого способа книги не показывают. §1.19.
- 📖 Сторона (Свет/Тьма) фиксируется при инициации и не меняется. Сменить
  цвет Силы могут **только высшие** — и то после невероятных событий
  (подтверждено автором). Рядовой Светлый не может «перейти к Тёмным» —
  максимум уйти со службы.
- 📖 Неинициированный Иной может дать стихийный выброс; инициация «дикого» —
  штатная работа Дозоров.
- 📖 Численность: в мегаполисе (Москва) — **несколько тысяч Иных**. Следствие
  для дизайна: ни один Иной не «монополист» на рынке услуг; конкуренция
  возникает из тесноты ниши (одинаковая специализация в одном районе), а не
  из дефицита Иных (подтверждено автором).
- 📖 **Большинство Иных в Дозорах не служат** — это гражданские: бармены,
  врачи, ремесленники. Они знают о системе, узнают своих и знают, «кому
  звонить» (подтверждено автором на инциденте №7).

## Договор и стороны

Правовая система подробно: [canon/4-treaty.md](canon/4-treaty.md); там же
§4.33 — сорок консолидированных правил и §4.34 — зоны свободного дизайна.

- 📖 Великий Договор между Светом и Тьмой. Ночной Дозор — Светлые, надзирающие
  за Тёмными; Дневной Дозор — Тёмные, надзирающие за Светлыми; Инквизиция —
  надзор над обоими.
- 📖B Договор — **перемирие из страха**, а не объединение: открытая война
  сторон погубила бы значительную часть человечества (каждый Иной способен
  повести за собой людей). Договор не примиряет идеологии, не создаёт общей
  этики и не запрещает интриги — он переводит войну в регулируемое
  противостояние. Финальная формула: итог определит время. §4.1.
- 📖A Договор — **не кодекс добра и зла**: Инквизиция карает нарушение
  Договора, а не моральную неправоту (Витезслав). Законное ≠ моральное:
  лицензированная охота вампира законна; спасение людей без права —
  нарушение. §4.2.
- 📖C **Люди — не сторона Договора**: не подписывали, не представлены, могут
  быть объектом лицензированного вмешательства. Договор защищает
  человечество как основу мира, но не каждого конкретного человека. §4.3.
- 📖A **Возраст: Договору столетия** (поздний канон; ранняя реплика «почти
  полвека» из «Ночного Дозора» отвергнута рамкой канона). Дата, место и
  подписанты не названы — E. §4.5.
- 📖B Основной текст короток, читается из возникающего в Сумраке текста
  (произнести по памяти нельзя — ПРОБЕЛ почему). Вокруг него — целый
  правовой массив: комментарии к соглашению о балансе, права, лицензии,
  патенты, регистрационные нормы, обычаи, прецеденты Трибунала, внутренние
  инструкции Дозоров. §4.4, §4.7.
- 📖B Договор **не предотвращает нарушения физически** — нарушение возможно,
  затем следы, расследование, претензии, суд, наказание. §4.6.
- 📖 **Тайна: люди не знают об Иных.** Сокрытие — базовое требование Договора
  для обеих сторон. Рассказывать людям об Иных, особенно массово, —
  **нарушение Договора** (подтверждено автором). Игровая механика «огласка» —
  это движение к нарушению Тайны; массовое раскрытие — тяжкое нарушение.
- 📖C Принцип равновесия вмешательств — канон, но НЕ автоматическая
  бухгалтерия. Формула «доброе действие даёт Тёмным право на злое» —
  каноническое объяснение Антона новичку, упрощение, не алгоритм: в книгах
  не показано, что жетон возникает после каждого заклинания, что ответ
  обязан быть той же степени, тем же типом, по тому же адресату или
  немедленно. Компенсация устанавливается соглашением/руководителями и
  может превышать номинал нарушения (Алиса: вмешательство III → Антону
  право до II). 🛠 Автоматический размен той же ступени в игре — наша
  сознательная формализация зоны E, не книжный закон. §4.12, §4.16–4.17.
- 📖 **Вмешательство = воздействие на человека, подталкивающее его к Свету
  или Тьме.** Светлое воздействие двигает человека к Свету, тёмное — к Тьме;
  и то и другое требует лицензии или санкции. Примеры: стирание памяти,
  внушение, исцеление, благословение, проклятие (подтверждено автором).
- 📖 **С собой и с неодушевлёнными предметами Иной может делать что угодно** —
  это НЕ вмешательство: погода, фонари, техника, собственный облик — свободная
  зона (подтверждено автором). Следствие: заклинание «Гремлин» (ломает
  технику) — легальный способ уничтожить нежелательные записи.
- 📖 **Правоприменение ≠ вмешательство.** Задержание нарушителя Договора и
  силовое пресечение нарушения — законные действия, лицензий противнику НЕ
  дают (подтверждено автором на инциденте №1).
- 📖 **Реестр — обычная бюрократическая база данных Дозоров**, никакой магии:
  Дозоры сами ведут учёт того, у кого какие права на воздействие на людей.
  Дозорный пишет протокол о всех применённых воздействиях — **но физически
  может и не записать**: умолчание — это сокрытие, оно существует ровно до
  тех пор, пока противник не вскрыл его сам (тогда — двойная компенсация и
  Арбитры). Будущая механика: игрок может рискнуть не задекларировать
  вмешательство (подтверждено автором).
- 📖 **Реестр — предмет юридической борьбы.** Своя сторона декларирует свои
  вмешательства; противник предъявляет те, что зафиксировал. Оперативники
  противника могут пытаться квалифицировать безобидные действия как
  вмешательства и «раскрутить на лицензии»; получив отпор по букве — давят
  «риском раскрытия Тайны» и угрозой передать дело Арбитрам (подтверждено
  автором на инциденте №7).
- 📖 **Сделки с противником легальны**: услугу (например, чистку памяти
  зевакам) можно купить за лицензию. Но их вмешательство подталкивает людей
  к их стороне — а одобривший сделку становится соучастником этого сдвига
  (подтверждено автором).
- 📖 **Реестр двусторонний: доказанное нарушение противника = санкции
  нарушителю + лицензии-компенсации пострадавшей стороне.** Доказав и
  оформив нарушение Тёмного (например, порчу без лицензии), Ночной Дозор
  получает лицензии-компенсации в свой Реестр — из них и складываются квоты
  на собственные вмешательства Света (подтверждено автором на инциденте №6).
- 📖 Ведьмины зелья **не маркируются** — это не государственная сфера, никакой
  «сертификации зелий» не существует. Нарушение — не зелье само по себе, а
  несанкционированное воздействие (порча без лицензии).
- 📖 **Санкции на вмешательства выдаёт руководство своего Дозора** — заявки на
  плановые и внеочередные вмешательства (в т.ч. жизненно важные исцеления)
  рассматривает начальство Стражи, не Инквизиция. Инквизиция (в игре —
  Арбитры) — надзор за соблюдением Договора МЕЖДУ сторонами и разбор
  нарушений (подтверждено автором).
- 📖 Зеркало: при сильном перекосе Баланса из Сумрака приходит Зеркальный
  маг — сила его растёт мгновенно до уровня противника; исчезает после
  восстановления равновесия («Дневной Дозор», Виталий Рогоза).
- 📖 Светлые ради великих целей манипулируют и жертвуют; Тёмные декларируют
  свободу и эгоизм. Моральная инверсия — ядро вселенной, беречь её.

### Степени вмешательств

- 📖B **Четыре разные шкалы** — не путать: уровень Иного / мощность
  заклинания / степень вмешательства (юридическая тяжесть) / наличие права.
  Иной 1-го уровня может не иметь права на вмешательство 5-й степени;
  слабый с артефактом может провести воздействие, которое сам не создал бы.
  §4.8.
- 🛠 Термин проекта: **«степень вмешательства»** (в книгах слова гуляют:
  степень/уровень/порядок; в карточках сохранять слово источника). §4.9.
- 📖B Шкала обратная: VII — слабейшая, I — тяжелейшая. Полного тарифника в
  каноне НЕТ — E. Подтверждённые точки: **VII** — грань магии и разговора
  (лёгкое усиление неприязни продавца к обману); **V** — изменение судьбы
  одного человека и одного Иного («Новый Дозор», внушение про утюг →
  снятие с обречённого рейса); **III** — дело Дарьи, Алиса с Призмой Силы;
  **I–II** — спасение полного самолёта (~200 человек). **VI** — чистого
  примера в гексалогии нет (D: «Светлая Тень» подтверждает существование).
  Юридической «нулевой степени» нет. §4.10.
- 📖A **Степень определяется результатом, не зрелищностью заклинания**:
  масштаб (сколько затронуто), статус цели (человек < Иной < сильный Иной),
  глубина изменения судьбы, служебный статус исполнителя, наличие права.
  Мелкое внушение может быть V степенью, если меняет судьбу. Опубликованной
  формулы нет — E. §4.11.
- 📖B Граница между соседними степенями бывает спорной (Дарья: оценка III–IV
  на месте, III в обвинении); квалификация уточняется расследованием. §4.10.4.

### Права и лицензии

- 📖A Существует **оперативный учёт прав**: удалённая проверка доступных
  степеней, выбор меньшего варианта, **запись вмешательства на конкретного
  исполнителя** («Новый Дозор»). §4.14.
- 📖A Права могут быть: общими для Дозора, закреплёнными за Иным,
  **зарезервированными руководителем лично** (Гесер и право I степени),
  выданными пакетом (Завулон: 3 × до III), ограниченными верхней степенью,
  предметом сделки. Биржа прав (продажа за деньги, дробление, курс
  конвертации) не показана — E. §4.14–4.15.
- 📖B **Личные соглашения и клятвы юридически значимы**: устная формула +
  рукопожатие (Антон—Алиса, взаимное прощение до VII); клятва,
  засвидетельствованная Изначальной Тьмой (Завулон). Юридическая форма — не
  только бумага: устно, рукопожатие, телефонная регистрация, клятва при
  Изначальной Силе, решение Трибунала, магическая печать. §4.7.5, §4.29.
- 📖B **Патенты** — постоянные профессиональные разрешения («чёрная магия
  без патента» в деле Дарьи), отдельные от разовых прав. Кто выдаёт, сроки,
  светлые аналоги — E. §4.13.
- 📖B **Служебное полномочие** — право на магию при исполнении, но не
  иммунитет: противник вправе проверить, был ли сотрудник на службе и
  соответствовало ли действие заданию. Сотрудник Дозора связан БОЛЕЕ
  строгими ограничениями, чем частный Иной. §4.7.3, §4.10.1.
- 📖B Вампирская лицензия — отдельный правовой режим: может допускать смерть
  жертвы, но задаёт допустимый максимум, не обязанность убивать (Эдинбург).
  Донорская кровь позволяет жить без убийства. §4.19.

### Инквизиция и Трибунал

- 📖A Инквизиция — **не третья Сила**: Светлые и Тёмные, сохранившие свою
  природу (Витезслав — Тёмный Высший вампир на службе Инквизиции), которых
  удерживает «ужас перед альтернативой». Численность — «не слишком много»,
  точных цифр нет. §4.21.
- 📖B Может судить руководителей Дозоров, конфисковывать артефакты,
  развоплощать, накладывать постоянные печати. Прага — Европейский
  Трибунал; Берн — схрон (не штаб); мировой центр не показан — E. §4.21–4.22.
- 📖B Трибунал: открывается чтением Договора; рассматривает иск + встречный
  иск + связанные дела; оценивает **и букву, и дух** (Гесер и Книга Судьбы:
  опасная манипуляция признана законной); учитывает смягчающие; обвиняемый
  **вправе не свидетельствовать против себя** (Завулон). Показанный состав —
  семь членов (не факт, что всегда). §4.23.
- 📖B Трибунал может **временно воплотить умершего Иного как добровольного
  свидетеля** (Алиса в теле живого носителя): чудовищно дорого, редко,
  умерший не может остаться. §4.24.
- 📖B Прецедент Гесера: косвенное стратегическое вмешательство (мелкие
  правки Книги Судьбы, сдвигающие вероятности к нужному исходу) может быть
  формально безупречным — Договор не закрывает все лазейки. §4.18.

### Наказания и санкции

- 📖B Виды приговоров различаются: **развоплощение** ≠ физическая казнь ≠
  **пожизненный запрет магии** (закрепляется постоянными печатями; могут
  оставить крохи бытовой магии — Братья Регина; запрет магического
  долголетия — отдельно). ❓ Развоплощение vs смерть vs посмертие в
  Сумраке — разобрать в разделе о шестом слое. §4.25.
- 📖B Внутренние санкции Дозоров: от взыскания старшего наряда до наказания
  Ольги (80 лет в теле совы — решением инстанции ВЫШЕ Гесера). Единой
  дисциплинарной лестницы нет — E; административное снижение природного
  уровня не подтверждено. §4.26.
- 📖B Мелкие нарушения урегулируются на месте: протокол, устное замечание
  или личное соглашение — но неудачная формулировка сделки создаёт будущую
  уязвимость. §4.18 (прецедент 1).

### Дуэли

- 📖B Дуэль — древний обычай ровесник Договора: для личных конфликтов, где
  у Дозоров нет права вмешаться. Ритуальный вызов — обращение к Свету И
  Тьме, «один на один, до конца»; Изначальный Свет подтверждает вызов белым
  огнём, Тьма принятие — сгустком темноты. §4.27.
- 📖B Отказаться МОЖНО — цена социальная (репутация, клеймо уклонившегося),
  не смертельная. Условия (место, время, вид поединка) выбирает вызванный;
  при отказе выбирать — вызвавший. Секунданты в показанном поединке не
  требуются; полного кодекса нет — E. §4.27.
- 📖B **Победитель всё равно отвечает перед Инквизицией**: проверяется
  правильность вызова, провокация, использование людей как наживки, ущерб
  посторонним. Дуэль легализует поединок, а не всё вокруг него. §4.27.5.

### Международность

- 📖B Договор глобален (московские Дозоры, Европейский Трибунал, шотландские
  Дозоры, бернский схрон), но практика локальна: эдинбургское вампирское
  сообщество живёт своими нормами и хочет наказывать своих само. Единого
  мирового полицейского корпуса нет. Экстрадиция, юрисдикции, признание
  иностранных лицензий — E. §4.28.4, §4.30.

## Сумрак

Подробно: [canon/2-twilight.md](canon/2-twilight.md); §2.27 — 60
консолидированных правил, §2.28 — 35 зон свободного дизайна.

### Структура и природа

- 📖A Слоёв шесть; **реальность — седьмой слой, структура замкнута в
  кольцо** («Последний Дозор», финал; в «Новом» — учебная модель первого
  месяца обучения). Ранняя трёхслойная модель — неполное знание Дозоров,
  получившее внутримировое объяснение. §2.1.
- 📖B Природа Сумрака неизвестна даже Высшим и Инквизиции: учебная формула —
  «слоистая параллельная реальность»; все теории происхождения — гипотезы
  персонажей. Нельзя объявлять каноном «мир мёртвых», «сон мира» и т.п.
  §2.2.
- 📖A **Сумрак жив, но не разумен** (Лилит, «Шестой Дозор»): стремится
  продолжать существование; Тигр — его разумный хранитель без собственной
  воли; Двуединый — порождение с разумом И волей; гибель всей жизни =
  гибель Сумрака; Иные — «паразиты и хранители» одновременно. §2.2.
- 📖B **Круговорот Силы**: жизнь производит Силу → поток через Сумрак →
  Иные и мох забирают часть → Сила возвращается в реальность, замыкая
  кольцо. Скорость и механизм — E. §2.3.

### Вход, выход, доступ

- 📖B Вход — через **истинную тень**, рождённую Сумраком, а не оптическую:
  на глубине тень может быть «внутри себя» (переход Антона на 5-й).
  Физический свет помогает найти вход, но НЕ установлен как обязательное
  условие; «залить светом = заблокировать» — не канон. У опытных вход
  рефлекторен. §2.4.
- 📖B Переход между слоями — снова поднять тень; на глубине это задача
  знания и состояния, а не только энергии. **Чистой Силы для некоторых
  границ недостаточно**: Высший Антон не мог войти на 5-й, пока не понял
  как; граница 6→7 растёт экспоненциально — даже Круг Силы не пробил бы.
  §2.4.3–2.4.4.
- 📖B Выход: базово — последовательный подъём по слоям («психологически
  проще искать выход позади»); **прямой выход с глубины в реальность —
  техника сильных и опытных** (Гесер из 5-го). §2.5.
- 📖B Первый слой осваивает любой нормально обученный Иной; потенциальный
  неинициированный может провалиться стихийно (Егор — до 2-го, под
  страхом/Зовом). Обычный человек себя в Сумраке не поддерживает; D:
  провести можно, но пассажир вытягивает Силу проводника (котёнок за
  секунды истощает молодого Иного — «Печать Сумрака»). §2.6, §2.20.
- 📖B **Таблицы «уровень → доступный слой» НЕТ**: глубина зависит от Силы,
  запаса, опыта, знания перехода, состояния, помощи. Ранг ≠ освоенная
  глубина (Высший Антон без 5-го; мастер-вампир Брюс дошёл до 4-го на
  грани гибели). 🛠 Для игры разносим глубину: теоретическая / освоенная /
  безопасная / с проводником / аварийная. §2.7.

### Цена и время

- 📖B Сила тратится на **две операции**: переход между слоями и поддержание
  жизни на слое (учебное определение). 2-й слой: потери каждое мгновение,
  холод, считаные минуты до риска раствориться. Формул расхода нет — E.
  §2.8.
- 📖A **Пятый слой — исключение: «энергетически сбалансирован»** — обычный
  отток исчезает, среда почти пригодна для жизни (но это не бесплатные
  переходы и не бессмертие). ⚠️ Расходится с GD-моделью монотонного роста
  утечки — см. «Расхождения дизайна с каноном». §2.14.
- 📖B **Время в Сумраке течёт медленнее реального**: погружение Алисы на
  1-й слой (правка памяти, осмотр, выжигание мха) заняло в реальности <2
  секунд; на 2-м жители 1-го — «едва движущиеся тени»; путь Завулона по
  2–3-му — субъективные часы/дни при минутах снаружи (предположение
  Антона). Коэффициентов нет — E. Замедление не бесплатно: каждый
  субъективный миг жжёт Силу. Канонная опора игровой сцепки «нырок
  экономит часы смены». §2.9.

### Слои: карточки

- 📖B **1-й**: реальность без красок; сумеречные двойники объектов имеют
  СВОЁ состояние (лифт — на 9-м этаже при реальном на 1-м; дверь заперта
  страхом, а не замком). Сквозь обычные стены — с разбега/усилием, но не
  бесплотность (магическая защита не проходится). Магия с 1-го слоя может
  бить в реальность — люди видят «удар из пустоты», не видя исполнителя.
  §2.10.
- 📖B **2-й**: вид зависит от места (туман / облачная пустота с тремя
  лунами / каменный лабиринт под ветвями); обычные конструкции могут
  отсутствовать — Останкинской башни нет, Антон падает; мха уже нет;
  тяжело даже опытным. §2.11.
- 📖B **3-й**: бытовая архитектура исчезает, остаётся магически и
  символически значимое (ритуальный стол, Кровавая река, следы смерти).
  Граница 2→3 может быть усилена и открываться живой кровью — переходы не
  везде одинаковы. С 3-го можно взглянуть в реальность. §2.12.
- 📖B **4-й**: серая пустыня с искрящимся цветными вспышками песком, чёрные
  валуны, бело-розовое небо без солнца; человеческой архитектуры нет.
  Температура субъективна: Антону холодно, Гесеру жарко. §2.13.
- 📖A **5-й**: холмы, колючая трава, гроза, молнии бьют из земли в небо,
  цвета почти вернулись; энергетически сбалансирован; древние конструкции
  хранятся веками (голем Мерлина — двухголовая глиняная змея на страже
  столетия). §2.14.
- 📖A **6-й — посмертие Иных**: личность, память, характер и отношения
  сохраняются; среда — убедительная **имитация жизни без её полноты**
  (вкус, свет, звук приглушены — можно веками не замечать подмены).
  Умершие **голодны по живой Силе**: прикосновение живого временно
  «оживляет» — и притягивает остальных. Подняться выше могут немногие
  (Мерлин — до 5-го), до 1-го — единицы, и там беспомощны. «Города Света и
  Тьмы, единороги» Лермонта — очарование слоя, НЕ подтверждены. Штатного
  воскрешения нет: Надя открыла путь — умершие остались. §2.15.
- 📖A **7-й = обычная реальность**: Надя (только что инициированная
  Абсолютная) шагом вперёд из 6-го вывела Антона на улицу Эдинбурга.
  Реальность настоящая, не «ещё одна серая зона». Кто ещё способен
  замкнуть кольцо — E. §2.16.

### Физика слоёв и взгляд

- 📖B Объект имеет **разные проявления по слоям** или отсутствует
  (эдинбургский страж: одна форма на 1-м, другая на 2-м, нет на 3-м);
  магически значимое проявляется глубже; по карте реальности глубину
  ходить опасно. Свежая смерть — «сильнейшая магия» — проявляется сразу
  на всех слоях (сроки/условия — E). Заклинание может действовать на
  одном или нескольких слоях (белая кобра — на всех, ценой огромной
  энергии жезла). §2.17.
- 📖A **Видеть и входить — разные способности** (закрыт открытый вопрос;
  наше старое правило пересмотрено): сильный Иной просматривает несколько
  слоёв не входя — Антон в «Шестом» смотрит сквозь ВСЕ; с глубины можно
  смотреть в реальность. Существует **пространство между слоями** —
  техника исключительных (Завулон); обычным сканом не видится. Дальность
  взгляда — формулы нет, E. §2.18.

### Предметы и тайники

- 📖B Автопереноса инвентаря НЕТ: удерживаемое и контролируемое проходит
  (сумка Антона), неудержанное остаётся (бутылка Афанди). Предмет можно
  **оставить** на 1-м слое (кроссовка в стене): тлеет месяцами, чуткие
  люди замечают краем глаза. Тайники принципиально возможны, механика — E.
  Мощные артефакты хранятся глубоко веками. §2.19.

### Низшие и животные

- 📖B **Вампиры — полноценные Иные, общие правила глубины**: слабые
  ограничены верхними слоями, мастер Брюс — 4-й на пределе, Высшие —
  глубже. ⚠️ «Полусумеречные существа» — НЕ канон гексалогии (D:
  «Сумеречные Иные» из «Печати Сумрака» — другое понятие); наша механика
  «1-й слой почти бесплатен низшим» — игровое допущение, см. «Расхождения».
  Оборотни: отдельных данных о глубине нет — E. §2.21.
- 📖B **Кошки живут во всех мирах одновременно** (кот Егора присутствует
  на 1-м и 2-м): видят гостей Сумрака, не нуждаются в переходе через тень.
  Не Иные, не проводники. Противоречие с котёнком-«пассажиром» из «Печати
  Сумрака» решено приоритетом основного канона. §2.22.

### Обитатели
- 📖 Синий мох живёт ТОЛЬКО на первом слое, питается эмоциями людей.
  Глубже — не растёт.
- 📖 Мох ест **яркие эмоции любого знака** — страх, радость, страсть ему
  безразличны. Плотность и свежесть узора говорят об интенсивности и
  регулярности эмоций, но НЕ об их знаке. (⚠️ Анти-ошибка: «кольцо мха =
  страх» — неверно; знак эмоций по узору без навыка не читается.)
- 📖 **Передозировка**: очень яркие эмоции — громкий смех, веселье, большое
  счастье — дают мху слишком много Силы разом и **выжигают его сами**.
  Колонию можно убить, перекормив радостью.
- 🛠 Чтение структуры мха — **навык**: базово любой Иной видит плотность и
  свежесть; со специальной подготовкой узор раскрывается глубже (знак эмоций,
  ритм, источник). Под взаимодействие со мхом — отдельная ветка навыков
  персонажа (см. GD).
- 📖 Съеденные мхом эмоции **переварены** — они не копятся в месте и не
  делают его привлекательным для Тёмных. (⚠️ Анти-ошибка: идея «прикормленное
  страхом место — накрытый стол для Тёмного» неверна, вычеркнута.)
- 📖C→🛠 Разросшаяся колония тянет эмоции из живущих рядом людей: апатия,
  депрессия, в пределе самоубийства. ⚠️ Уточнение по канон-исследованию
  (§2.23.1): в книгах обратное влияние мха на психику — **недоказанная
  гипотеза персонажей** (Антон подчёркивает это прямо); в игре принята как
  факт мира — 🛠, несущая механика инцидента №2.
- 📖B Мох горит как порох, разрушается огнём и холодом, может ползти от
  источника тепла; отделённый от колонии фрагмент способен гибнуть сам.
  §2.23.1.
- 📖 Дозорные штатно **выжигают мох** (Сила и время, лицензий не тратит —
  техническая работа на Изнанке). Если первопричина эмоций не устранена,
  колония возвращается за 2–3 недели.
- 📖A **Естественной фауны в Сумраке нет.** Надёжные обитатели: синий мох,
  умершие Иные (6-й слой), Тигр, Двуединый, магические конструкции
  (голем Мерлина, стражи — артефакты, не звери). «Десятки сумеречных
  монстров» вводить нельзя — подтверждает наш принцип «оружие Сумрака —
  утечка, а не мобы». §2.23.

### Перемещение

- 📖B **Сумрак ≠ портал.** 1-й слой сохраняет топологию города: выигрыш во
  внешнем времени, скрытность и обход препятствий — не телепорт. Глубже
  геометрия ломается (путь может стать короче ИЛИ опаснее). Дальняя
  мгновенная переброска — отдельная портальная магия (Тёмный Портал
  Завулона выжигает мох в точке выхода, дорого по Силе). Коэффициентов
  сокращения расстояния нет — E. §2.24.

### Смерть и посмертие

- 📖C Различать четыре состояния: **физическая смерть** (личность → 6-й
  слой) / **истощение живого в Сумраке** (растворение) / **развоплощение**
  (приговор или магия) / **окончательное уничтожение** сумеречной
  личности. Полной схемы их связи в книгах нет — частично E. Безопасная
  формулировка: обычная смерть ведёт на 6-й слой; истощение и
  развоплощение могут иметь иные последствия. §2.25.

## Классы Иных

### Вампиры

- 📖 Низшие Иные. Нуждаются в крови; Зов приманивает жертву; обращение укусом.
- 📖 Охота — только по лицензии; безлицензионная охота (браконьерство) —
  преступление, штатный сюжет Дозоров.
- 📖 **Лицензия на охоту выдаётся на конкретного человека** (ФИО). Жертв
  выбирает так называемая **вампирская лотерея**.
- 📖 Лотерея и лицензия опираются на ФИО и ауру; **у близких родственников
  ауры похожи** — полный тёзка с родственной аурой может быть перепутан с
  настоящей жертвой (источник трагических ошибок).
- 📖A Поздний канон: **дети младше 12 лет исключены из лотереи** («Шестой
  Дозор»; в «Последнем» эдинбургская практика была мягче формально, жёстче
  фактически — разрешено правилом позднего канона). Прочие «защищённые
  категории» (беременные, знаменитости — слова Евы) НЕ подтверждены: Антон
  отрицает. §4.20 canon/4-treaty.md.
- 📖A Лицензия задаёт допустимый **максимум**, не обязанность: эдинбургские
  вампиры и с лицензией стараются не убивать. Донорская кровь позволяет
  жить без убийства («20% донорской крови — вампирам» — реплика Кеши,
  внутреннее свидетельство, не норма). §4.19–4.20.
- 📖A Древние разрешения на кормление (на бересте, глиняных табличках — у
  Евы) могут храниться веками и восприниматься как действующие; признаёт ли
  их современный учёт — ПРОБЕЛ. §4.20.4.
- E Процедура лотереи (кто проводит, частота, пул, уведомление жертвы,
  выкуп/замена, добровольцы, срок лицензии) в книгах не описана — зона
  свободного дизайна. §4.20.6.
- 📖 Выпитая кровь усиливает вампира; сильные вампиры — серьёзные противники.
- 📖 **Серебро** эффективно, но ненамного эффективнее обычных пуль: слегка
  замедляет регенерацию именно этих ран. Не «уязвимость», а тактический нюанс.
- 📖 **Серый молебен** — заклинание против всей нежити (не только вампиров).
  Вампиров замедляет, ослабляет, высасывает из них Силу; может развеять.
- 🛠 Два пула (долгосрочный от жертв, оперативный от донорской крови) — наш
  дизайн поверх канона.

### Регистрационная печать (вампиры и оборотни)

- 📖 Законопослушные вампиры и оборотни носят регистрационную печать.
- 📖 Печать — это одновременно **бомба, прикреплённая к ауре**, и **магический
  паспорт**: где зарегистрирован, кем поставлена, нарушения Договора, уровень
  Силы носителя и т.д.
- 📖 Паспортная информация получается **считыванием печати на носителе** —
  отдельного «досье печати» с удалённым доступом не существует; чтобы читать
  печать, нужен её носитель рядом (подтверждено автором).
- 📖 Печать показывает только **зафиксированные** нарушения — запись вносит
  дозорный. Непойманное преступление в печати не появится само собой: как в
  паспорте видны судимости, но не кражи, за которые не поймали. **Чистая
  печать ≠ невиновность** — это лишь «ни разу не ловили» (подтверждено
  автором).
- 📖 **Печати ставят Светлые (Ночной Дозор)**, не Инквизиция. Реестр печатей,
  канцелярия, перерегистрация — всё это хозяйство самой Стражи.
- 📖 Поставить, заглушить или снять печать может **только сильный Иной —
  от 2-го уровня и выше**. Низшему 5–7 уровня она не по зубам в принципе.
  Следствие для дизайна (🛠): заглушённая печать у слабого низшего — улика
  присутствия сильного сообщника, а не проступок носителя.
- 📖 Печать **не отслеживает кормление и охоту** — глушить её «перед делом»
  незачем. Её смысл в другом: при поимке нарушителя не будет схватки.
- 📖 **Активация не требует от дозорного даже Силы и убивает носителя
  мгновенно.** Дозорный вправе проверить печать при встрече.
- 📖 Основание для активации — только тяжкие нарушения (убийство, незаконная
  охота). Просрочка перерегистрации и прочая бюрократия основанием НЕ
  являются (подтверждено автором).
- 📖 **Нападение на дозорного при исполнении — тяжкое нарушение** и даёт
  основание для активации печати прямо на месте (подтверждено автором).

### Оборотни

- 📖 Низшие Иные, Тёмные.
- ⚠️ 📖 **К лунному циклу НЕ привязаны** — оборачиваются по собственной воле.
  Классическое вервольф-клише в этой вселенной не работает. (Поймано в v0.10:
  успело просочиться в GD и прототип, вычищено.)
- 🛠 Молодой нерегистрированный оборотень может терять контроль над первой
  трансформацией (эмоциональный триггер) — наш геймплейный акцент, канону
  не противоречит.
- ⚠️ ❌ «Территориальные метки» (борозды на бетоне, запаховая разметка
  угодий) — НЕ канон, отклонено автором. Следственная сигнатура оборотня:
  очевидцы «зверя в городе», шерсть и следы когтей на местах нападений,
  характер ран жертв.
- 📖 Оборотень может **обратить человека**. Обращение без санкции —
  браконьерство, тяжкое нарушение. Новообращённый — жертва: он мог даже не
  слышать о Дозорах и не понимать, что с ним происходит (подтверждено
  автором).

### Перевёртыши

- 📖 Светлые маги с боевой звериной формой (Тигрёнок, Медведь — «Ночной
  Дозор»). Людей не едят; экономика Силы — маговская.

### Ведьмы/ведьмаки и ведуньи/ведуны

- 🎮 Парный класс обеих сторон: ведьма/ведьмак у Тьмы, ведунья/ведун у Света;
  механически идентичны, различие — сторона Силы.
- 🎮 Единственный класс, создающий артефакты; арсенал: сглаз, проклятия,
  зелья в обе стороны (яды И лечение), привороты И отвороты.
- 📖 В книгах ведьмы — предметно-ритуальная магия, обычно Тёмные (нюанс:
  книжного подтверждения светлой ветви класса нет — опираемся на онлайн-игру).

### Инкубы и суккубы

- 🎮 Класс Тёмных; обаяние/очарование, питание эмоциями.
- 🛠 Светлого зеркала не имеют (как и вампиры) — асимметрия ростеров.

### Целители

- 📖 Специализация Светлых магов (Светлана — целительница), не отдельный
  класс с собственной экономикой.

## Магия и Сила

Физика Силы подробно: [canon/1-power.md](canon/1-power.md); там же §1.20 —
шестнадцать консолидированных правил.

- 📖B Сила — рассеянная магическая энергия мира; Иные её не производят, а
  воспринимают, поглощают, копят, проводят, передают и вкладывают в
  артефакты. Главный источник — люди: эмоции, массовые состояния,
  жизненная активность (мегаполис богат Силой из-за людности). Животные,
  предметы и места имеют ауру, но как восполняемый источник ограничены или
  не показаны; предмет — накопитель следов, не генератор; растения — E.
  §1.1–1.2.
- 📖C **Питание Света и Тьмы**: предпочтительные эмоциональные спектры
  (Светлые — радость, любовь, надежда, доверие; Тёмные — страх, гнев,
  зависть, похоть), но ЖЁСТКОГО физиологического запрета на «чужой» спектр
  НЕТ — различие в направлении личности и способе взаимодействия с людьми.
  «Светлая» кормёжка тоже не безобидна: можно оставить человека
  опустошённым, без радости и доброго импульса. ⚠️ Анти-ошибка: «Светлые
  физически не могут взять страх» — неверно, это упрощение адаптаций.
  🛠 Игровая специализация по эмоциональным источникам допустима, но не
  маркируется книжным законом. §1.3–1.4.
- 📖B Последствия откачки для человека — спектр по способу и глубине:
  пассивное рассеивание (незаметно/лёгкая усталость) → направленное снятие
  эмоции (апатия, подавленность) → вампирское кормление (отдельная
  физиология: кровопотеря, шок, риск смерти) → откачка жизненной энергии
  (истощение, болезнь, смерть). Числовой шкалы в каноне нет — E, игровая
  формализация. §1.5.
- 📖B Передача Силы между Иными: добровольно — канон (напрямую, амулет,
  накопитель, коллективно в ритуале); принудительно — возможно при
  превосходстве/спецзаклинании/артефакте/особой природе (вампиры умеют
  пить Силу Иных). Топливо ≠ двигатель: уровень, знания, специализация и
  контроль не передаются. §1.6.
- 📖B Восстановление: время, отдых, сон, еда, люди вокруг; после тяжёлой
  магии — голод, тяга к сладкому, слабость, «постзаклинательная депрессия»
  («Шестой Дозор»; там же — существование собственно «иных» болезней).
  Формулы скорости нет — E. Вампиры восстанавливаются кормлением; у ведьм
  «восстановление» — это подготовка внешних накопителей. §1.7.
- 📖B Перекачка сверх обычного объёма возможна (союзники, накопители,
  мощный эмоциональный поток). Различать пять параметров: запас,
  проводимость, контроль, уровень, знание заклинания. Перегрузка: потеря
  контроля, выброс, истощение, срыв заклинания, постзаклинательная
  депрессия, в пределе — смерть/развоплощение. Сила лишь частично
  компенсирует навык («Шестой Дозор»: Антон читает ауру кастрюли за
  недельный запас энергии). ⚠️ Термин «перегрев» — 🛠 игровой, в книгах
  такой характеристики нет. §1.8.
- 📖B Слабый Иной может ударить выше своего уровня: накопитель, одноразовый
  артефакт, подготовленное заклинание, поддержка других, ритуал,
  внезапность. Без гарантий: может не суметь сформировать, контролировать,
  дозировать, защититься от отдачи. Собственный уровень при этом НЕ растёт.
  §1.11.
- 🔮 «Магическая температура» (человек «горячий», Иной «холодный», энергия
  перетекает к холодному; сильный Иной забирает её непроизвольно) —
  объяснительная модель «Вечного Дозора». Приборов и научной шкалы в мире
  нет; твёрдой механикой и числами не делать. §1.1.
- 📖 Заготовки заклинаний «вешаются» заранее — на рефлекс, на кончики пальцев;
  такие срабатывают мгновенно. Остальное плетётся с затратой времени.
- 📖 Канонные заклинания (для плейсхолдеров): Пресс, Фриз, Морфей, Опиум,
  Тройное лезвие, Файербол, Доминанта, Сфера невнимания, Реморализация,
  Щит мага, **Гремлин** (ломает технику — а техника неодушевлённая, поэтому
  без лицензий). ❓ точные эффекты части из них — сверить с текстом.
- 📖 Откачка Силы от людей — норма жизни Иных, не преступление.
- 🛠 «Законная» и «жадная» откачка с растущим риском — наш дизайн.
- 🛠 Перекачка мага сверх пула; потолок ведьм в рамках пула — наш дизайн по
  мотивам иерархии классов.

## Анти-клише: чего в этой вселенной НЕТ

Список пойманных жанровых штампов, которые НЕ из канона. Пополнять при каждой
находке — это прививка от следующих ошибок.

1. ❌ Оборотни и полнолуние — не привязаны (см. выше).
2. ❌ Серебро как «убийца вампиров» — преувеличение: работает лишь чуть лучше
   обычных пуль (подтверждено автором, см. раздел «Вампиры»).
3. ❓ Солнце, чеснок, осиновые колья, святая вода — эффективность в каноне
   не подтверждена; не использовать без проверки.
4. ❌ «Светлые питаются только позитивными эмоциями, Тёмные — только
   негативными» — упрощение пересказов и адаптаций: канон даёт
   предпочтительные спектры без физиологического запрета
   (canon/1-power.md §1.4).
5. ❌ Аура как интерфейс с точной карточкой («вампир, ур. 4, запас 73%») —
   чтение ауры зависит от наблюдателя и маскируется (§1.15–1.19).
6. ❌ Рост уровня как RPG-прокачка тренировкой — уровень растёт только через
   раскрытие потенциала или исключительное событие (§1.9).
7. ❌ «Реестр — автоматическая магическая бухгалтерия: каждое заклинание
   мгновенно рождает у противника жетон той же ступени» — это упрощение
   Антона для новичка; в каноне права резервируются, делегируются,
   торгуются, а компенсация — предмет переговоров (canon/4-treaty.md
   §4.12). В игре автоматический размен — сознательная 🛠 формализация.
8. ❌ «Степень вмешательства = мощность/зрелищность заклинания» — степень
   определяется юридическим результатом: масштабом, статусом цели, глубиной
   изменения судьбы (внушение про утюг — V степень) (§4.10–4.11).
9. ❌ «Инквизиция — третья, серая сила» — нет: это Светлые и Тёмные,
   сохранившие свою природу; карают нарушение Договора, не моральную
   неправоту (§4.21).
10. ❌ «Дуэль легализует всё» — победитель отвечает перед Трибуналом за
    провокацию, людей-наживку и ущерб посторонним (§4.27).
11. ❌ «Осветить помещение со всех сторон = Иной не сможет нырнуть» —
    не канон: вход через истинную тень, а не оптическую
    (canon/2-twilight.md §2.4.2).
12. ❌ «Слой N — глобальный одинаковый биом» — один слой выглядит
    по-разному в разных местах; устойчиво только удаление от человеческой
    геометрии (§2.11, §2.26).
13. ❌ «Уровень Иного автоматически открывает слой N» — таблицы
    «уровень → слой» нет; ранг ≠ освоенная глубина (§2.7).
14. ❌ «Шестой слой — рай Иных с городами и единорогами» — это очарование
    слоя (версия Лермонта); на деле — имитация жизни без её полноты
    (§2.15).

Механики GD, которым канон-исследования противоречат или которые он не
подтверждает. Правило LORE.md «канон побеждает дизайн» требует по каждому
явного решения: привести GD к канону или оставить как помеченное 🛠
игровое упрощение.

1. **Правило взгляда.** GD 5.7: «потолок взгляда = потолок шага». Канон
   (§2.18): видеть и входить — независимые способности; сильные смотрят
   сквозь несколько слоёв, с глубины можно смотреть в реальность. Варианты:
   принять канон (скан-действие глубже своего шага, отдельная
   прокачиваемая способность) или оставить упрощение как 🛠.
2. **«Полусумеречные» вампиры/оборотни.** GD 5.7: низшим 1-й слой почти
   бесплатен, глубже практически закрыто. Канон (§2.21): низшие —
   полноценные Иные с общими правилами; предел индивидуален (Брюс — 4-й
   слой). Механику можно сохранить как баланс классов, но термин
   «полусумеречные существа» и обоснование «природой» из текстов убрать.
3. **Монотонный рост утечки с глубиной.** GD 5.7: каждый слой глубже —
   резко больше утечка. Канон (§2.8, §2.14): 5-й слой энергетически
   сбалансирован — отток исчезает. Варианты: ввести особый статус 5-го
   (красивый твист поздней игры: «глубина-оазис») или упростить с
   пометкой 🛠.
