# Магия — рабочий разбор для своих заклинаний

> Подход (по решению арбитра): из канонной таблицы берём **название + примерную
> суть**, а механику придумываем свою. Ниже каждое заклинание отнесено в одну из
> двух корзин:
>
> - **✅ Понятно** — я уверенно вижу, *что оно делает* (категория и, для урона,
>   элемент). Отсюда сразу можно лепить нашу механику.
> - **❓ Придумать вместе** — есть хоть малейшее сомнение (неясен элемент, эффект
>   спрятан за «150% на 3 хода», имя-флавор ничего не говорит и т.п.).
>
> **Обновление:** после разбора получена сохранённая канонная таблица —
> `docs/MAGIC_TABLE.md` теперь содержит настоящую колонку **Тип (элемент)** и флаг
> «Бой». Поэтому **элементы больше не гадаются** (Белый меч = Огонь, Слеза Скорби =
> Ментальное, Молния = Энергетическое и т.д.). В «придумать вместе» ниже остаются,
> по сути, только **механики**: ВК-ультимейты «150% на 3 хода», проценты
> Прорицания и самобаффы (Морок, Зеркальные подобия — в каноне «на себя»).
>
> Категории, которыми размечаю: `урон [элемент]`, `лечение`, `щит`,
> `контроль` (сон/страх/обездвиж/оглушение), `бафф`, `дебафф`, `дренаж`
> (энергии/жизни), `утилита` (портал/анализ/поиск/скрытность/трансформация),
> `иллюзия`, `чарм`, `снятие` (диспел), `социальное` (влияние на людей).
> Источник названий — `docs/MAGIC_TABLE.md`. Порядок — по школам.

## Колдовство — огонь и молнии

**✅ Понятно:**
- Вифлеемский огонь — урон огнём (базовый)
- Цепной разряд — урон молнией (цепной/по нескольким)
- Файербол — урон огнём
- Разящая молния — урон молнией
- Защита Лужина — щит (несколько зарядов)
- Паучье пламя — урон огнём (возможно, многоударный)
- Групповой файербол — урон огнём (по площади)
- Молния — урон молнией (по площади)
- Поток лавы — урон огнём

**❓ Придумать вместе:**
- Белый меч — урон, но элемент неясен (физ? свет?)
- Плеть Шааба — урон, имя-флавор, элемент неясен
- Огненное безумие (ВК) — «150% на 3 хода»: бафф урона? поджог? ярость?
