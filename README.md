# Смена

Инди-игра по мотивам принципов вселенной Дозоров: roguelite-детектив о ночной
смене оперативника Стражи. Каждое вмешательство Света даёт Тьме право на ответ
той же силы — побеждает тот, кто платит меньше.

Полный дизайн-документ: [docs/GAME_CONCEPT.md](docs/GAME_CONCEPT.md).

## Статус

**Этап 0 — прототип ядра**: одна смена, процедурные инциденты, шкала Баланса,
Реестр лицензий, ответный ход Тьмы, утренний отчёт с оценкой. Сид смены — в URL
(`?seed=...`), одна и та же смена воспроизводится по сиду.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в dist/
```

## Стек

TypeScript + Vite, ванильный DOM. Контент (инциденты, ответки Тьмы) — данные в
`src/game/data.ts`, добавляются без изменения движка.
